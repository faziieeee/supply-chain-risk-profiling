# Supply Chain Risk Profiling

## Project Overview

This project focuses on **data-driven risk profiling for supply chain management**.
It analyzes supplier-related risks using weighted scoring techniques and categorizes suppliers based on their risk levels.

---

## Objectives

* Identify high-risk suppliers
* Analyze multiple risk factors
* Assign weighted scores to each factor
* Classify suppliers into risk tiers

---

##  Tools & Technologies

* Python 
* Pandas
* NumPy
* Matplotlib / Seaborn
* Jupyter Notebook

---

##  Project Structure

* `risk_profiling.ipynb` → Main analysis notebook
* `risk_profiling_results.csv` → Output results
* `HLD.pdf` → High-Level Design
* `LLD.pdf` → Low-Level Design
* `risk_dashboard.png` → Visualization

---

## How It Works

1. Data is collected for multiple suppliers
2. Risk factors are defined (e.g., delivery delay, quality issues, cost fluctuation)
3. Each factor is assigned a weight
4. A final risk score is calculated
5. Suppliers are categorized into:

   * Low Risk
   * Medium Risk
   * High Risk

---

## Output

* Ranked list of suppliers
* Risk score for each supplier
* Visual dashboard for insights
